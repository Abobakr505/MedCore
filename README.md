# Med Core — منصة التعليم الطبي

مشروع كامل: React + TypeScript + Vite + Tailwind CSS + Supabase.

## 1. المتطلبات

- Node.js 18+
- حساب [Supabase](https://supabase.com) (مجاني للبدء)

## 2. إعداد قاعدة البيانات (مرة واحدة فقط)

1. أنشئ مشروع جديد على Supabase.
2. من SQL Editor، شغّل ملف `database/01-schema.sql` كاملاً (من مخرجات Phase 1).
3. من Storage، تأكد من ظهور الـ Buckets التالية (يُنشئها السكربت تلقائيًا):
   `avatars`, `course-thumbnails`, `course-videos`, `payment-receipts`, `ticket-attachments`.
4. من Authentication → Settings، فعّل "Confirm email" (مفعّل افتراضيًا).
5. (اختياري لكن موصى به) انشر Edge Functions:
   ```bash
   supabase functions deploy get-lesson-video-url
   supabase functions deploy create-admin-user
   ```
   بدون نشر `get-lesson-video-url`، لن تعمل مشاهدة فيديوهات الدروس المدفوعة.

## 3. تشغيل المشروع محليًا

```bash
npm install
cp .env.example .env
# افتح .env وضع القيم من: Supabase Dashboard → Project Settings → API
npm run dev
```

سيعمل المشروع على: http://localhost:5173

## 4. إنشاء أول حساب أدمن

لا يوجد تسجيل عام لحساب الأدمن (بتصميم مقصود لأسباب أمنية). لإنشاء أول حساب أدمن:

**الطريقة الأسهل (يدويًا):**
1. سجّل حسابًا عاديًا (كطالب) من صفحة التسجيل.
2. من Supabase Dashboard → Table Editor → جدول `profiles`، عدّل قيمة `role` لهذا المستخدم يدويًا إلى `admin`.

**الطريقة الموصى بها للإنتاج:** استخدم Edge Function `create-admin-user` (راجع تعليقاتها في `supabase/functions/create-admin-user/index.ts`) مع ضبط متغير بيئة `ADMIN_SETUP_SECRET` سرّي، ثم استدعِها مرة واحدة فقط عبر `curl` أو Postman، ثم عطّلها أو احذفها.

## 5. البناء للإنتاج

```bash
npm run build
```

الناتج في مجلد `dist/` جاهز للنشر على أي استضافة ثابتة (Vercel, Netlify, Cloudflare Pages...).

## 6. ما الذي يعمل فعليًا الآن، وما الذي يحتاج استكمالًا

هذا تسليم Phase 1-6 مبني على نطاق واسع جدًا؛ فيما يلي وضعه بصدق:

### ✅ جاهز وشغّال بالكامل (منطق حقيقي متصل بـ Supabase، وليس بيانات وهمية):
- المصادقة الكاملة (تسجيل/دخول/تفعيل بريد/استرجاع كلمة مرور) + RLS.
- تصفّح/بحث/فلترة/ترتيب الكورسات + صفحة تفاصيل + معاينات مجانية.
- السلة، إتمام الشراء، رفع إيصال الدفع اليدوي.
- لوحة الطالب: كورساتي، التعلّم (فيديو + تقدّم + إكمال دروس)، الاختبارات (أداء وتصحيح آمن عبر RPC)، الدرجات، سجل المدفوعات، الدعم الفني، الملف الشخصي.
- لوحة المعلم: إدارة الكورسات (CRUD)، بناء المحتوى (أقسام/دروس/رفع فيديو/معاينة)، بناء الاختبارات، مراجعة المدفوعات، قائمة الطلاب.
- لوحة الأدمن: الطلاب، المعلمون، الكورسات، المدفوعات، الاشتراكات، الشكاوى، الأجهزة (Device Lock)، الإعدادات، التقارير الأساسية.
- قفل الجهاز (Device Lock) بمنطق كامل على قاعدة البيانات + الفرونت إند.
- حماية فيديوهات الدروس عبر Edge Function + Signed URL (تحتاج نشر الـ Function لتعمل فعليًا).

### ⚠️ يحتاج ضبطًا أو اهتمامًا إضافيًا قبل الإنتاج الفعلي:
- **الدفع البنكي:** بيانات الحساب البنكي في `CheckoutPage.tsx` وهمية — استبدلها ببياناتك الحقيقية.
- **رفع الفيديو الكبير:** الرفع الحالي عبر `supabase.storage.upload` مباشر ومناسب لملفات متوسطة الحجم؛ لفيديوهات طويلة/كبيرة جدًا يُفضّل التحويل إلى Resumable Upload (TUS) الذي توفره Supabase.
- **التقارير:** `ReportsAdminPage` تعرض إحصائيات أساسية فقط؛ رسوم بيانية تفصيلية (نمو شهري، أداء كل معلم) تحتاج استعلامات إضافية.
- **SEO المتقدم:** العناوين والوصف الأساسي موجودة في `index.html`، لكن Sitemap.xml وRobots.txt وMeta الديناميكية لكل صفحة كورس لم تُضَف بعد (تحتاج Server-Side Rendering أو حل مثل `react-helmet` + Prerendering لتعمل بفعالية مع محركات البحث).
- **اختبار شامل لكل حالة حافة:** المشروع لم يُختبر يدويًا على كل متصفح/حجم شاشة بعد — التصميم Responsive بالكامل تقنيًا (Tailwind + مبادئ Mobile-first) لكن يستحق مراجعة بصرية قبل الإطلاق.
- **الأنيميشن:** تم استخدام Framer Motion لانتقالات ناعمة (Fade/Scale/Hover)، لكن مستوى "micro-interactions" الدقيق جدًا (مثل GSAP timeline معقدة) لم يُضف — يمكن إضافته لاحقًا دون تغيير الهيكل.
- **الإنجليزية:** البنية جاهزة لإضافة i18n لاحقًا (لا يوجد ربط فعلي بمكتبة ترجمة بعد، بناءً على طلبك أن العربي فقط مطلوب الآن).
